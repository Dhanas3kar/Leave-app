LeaveSync

A Distributed, Production-Ready Leave Management Prototype

Internship Hiring Assessment Submission

1. The Problem & Requirements

  • Goal: Build a robust web application that handles a specific workflow with real rules and edge cases.
  • Target Scenario: Leave Management (Requesting, Approving, Rejecting, and Quotas).
  • Challenge: Close the build → test → fix loop using AI automation, ensuring high-quality tests that can genuinely fail when broken.
Slide 2 / 5

2. Approach & Architecture

  • Micro-Frontend Monorepo: Separate `employee-portal` and `manager-portal` for strict security and concern separation.
  • Tech Stack: Next.js 15 (App Router) + React 19 Server Actions.
  • Database: Shared SQLite database manipulated safely via Prisma ORM atomic transactions.
  • Authentication: Stateless JWT HTTP-only cookies using `jose` and `bcryptjs`.
Slide 3 / 5

3. The Solution & AI Integration

  • Zero-API Design: Using Next.js Server Actions completely removed the need for fragile REST APIs.
  • AI-Driven Testing: Playwright was orchestrated via AI to map complex workflows (register → login → request → logout).
  • The AI Change Loop: AI was used to visually debug E2E test failures. It correctly diagnosed that Playwright was clicking a globally rendered "Logout" button instead of the form's "Submit" button, resulting in a flawless automated fix.
